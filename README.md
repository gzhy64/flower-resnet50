# 基于手写 ResNet50 的花卉图像分类

本项目使用 PyTorch 的基础模块，自行实现 ResNet50，完成五类花卉图片的分类。

模型从随机初始化开始训练，不调用现成的 ResNet50，也不使用 ImageNet 等外部预训练权重。数据增强使用 torchvision 提供的图像变换。

## 1. 项目功能

目前已经实现：

- 按类别文件夹读取图片，并自动建立类别编号。
- 按类别分别划分训练集、验证集和测试集。
- 手写 Bottleneck 残差块和完整 ResNet50。
- 默认对训练图片进行数据增强。
- 使用 SGD、余弦退火学习率和标签平滑训练模型。
- 根据验证准确率保存最佳模型。
- 为每次训练保存独立的配置文件和指标文件。
- 在测试集上评估指定模型。
- 使用指定模型预测单张图片。
- 绘制训练与验证的损失、准确率曲线。


## 2. 项目结构

项目可以放在任意目录，以下以 `flower-class` 作为项目文件夹名称：

```text
flower-class/
├── config.py             # 训练配置及默认参数
├── datasets.py           # 数据读取、类别映射和数据划分
├── models.py             # 手写 Bottleneck 和 ResNet50
├── engine.py             # 单轮训练与评估
├── experiment.py         # 实验目录、配置和指标保存
├── train.py              # 训练入口
├── test.py               # 测试集评估入口
├── predict.py            # 单张图片预测入口
├── plot_history.py       # 训练曲线绘制入口
├── environment.yml       # Conda 环境说明
├── flower_photos/        # 图片数据集
└── runs/                 # 实验记录和模型检查点
```

各模块的职责如下：

| 文件 | 主要职责 |
|---|---|
| `config.py` | 使用数据类集中管理训练参数 |
| `datasets.py` | 收集图片路径、读取图片、生成数据划分索引 |
| `models.py` | 定义网络结构和前向传播 |
| `engine.py` | 实现可重复调用的训练、评估函数 |
| `experiment.py` | 管理每次实验的输出文件 |
| `train.py` | 组织数据、模型、优化器和训练循环 |
| `test.py` | 加载最佳模型并评估测试集 |
| `predict.py` | 加载最佳模型并预测一张图片 |
| `plot_history.py` | 读取 CSV，生成训练曲线 |

这种结构将数据处理、模型定义、训练逻辑和实验管理分开，便于逐步理解和修改。

## 3. 数据集

### 3.1 目录格式与类别

数据集采用“一类一个文件夹”的形式，每张图片只有一个类别：

```text
flower_photos/
├── daisy/
├── dandelion/
├── roses/
├── sunflowers/
└── tulips/
```

程序按文件夹名称排序建立类别映射：

| 类别编号 | 类别名称 | 中文名称 | 图片数量 |
|---|---|---|---:|
| 0 | daisy | 雏菊 | 633 |
| 1 | dandelion | 蒲公英 | 898 |
| 2 | roses | 玫瑰 | 641 |
| 3 | sunflowers | 向日葵 | 699 |
| 4 | tulips | 郁金香 | 799 |
| 合计 | | | 3670 |

程序识别 `.jpg`、`.jpeg` 和 `.png` 文件，读取后统一转换为 RGB。

源码仓库默认不包含原始图片。使用前，请将完整的 `flower_photos` 数据集放在项目根目录下。

### 3.2 数据划分

当前使用约 80% / 10% / 10% 的比例，分别作为训练集、验证集和测试集。

划分时先按类别分组，再在每个类别内部随机打乱并取整，因此实际数量为：

| 类别 | 训练集 | 验证集 | 测试集 |
|---|---:|---:|---:|
| daisy | 506 | 63 | 64 |
| dandelion | 718 | 89 | 91 |
| roses | 512 | 64 | 65 |
| sunflowers | 559 | 69 | 71 |
| tulips | 639 | 79 | 81 |
| 合计 | 2934 | 364 | 372 |

数据划分种子固定为 `42`，与训练随机种子 `2026` 分开使用。

在当前样本列表下，三个子集的图片索引没有交叉。这项检查不等同于检查图片内容是否存在重复或近似重复。

三个子集分别承担以下任务：

- 训练集用于更新模型参数。
- 验证集用于选择训练方案和最佳模型。
- 测试集用于评估选定模型的最终表现。

当前保留原有划分，便于比较不同训练结果。若以后修改比例，需要同步修改训练和测试的划分规则，并保存具体样本名单。

## 4. 图片预处理

### 4.1 训练阶段

默认使用以下数据增强：

1. 随机裁剪并缩放为 `224 × 224`，裁剪面积比例为 `0.8～1.0`。
2. 以 `0.5` 的概率进行水平翻转。
3. 在正负 `10°` 范围内随机旋转。
4. 随机调整亮度、对比度和饱和度。
5. 转换为张量。

亮度、对比度和饱和度的扰动参数分别为 `0.15`、`0.15` 和 `0.1`。

增强在读取图片时执行，不会额外生成并保存一份图片数据集。

### 4.2 验证、测试和预测阶段

统一使用：

1. 将图片缩放为 `224 × 224`。
2. 转换为张量。

单张图片的张量形状为：

```text
[3, 224, 224]
```

一个批次的张量形状为：

```text
[B, 3, 224, 224]
```

其中 `B` 表示批次大小。

当前输入为 `float32`，像素值范围为 `[0, 1]`，没有额外使用 `Normalize`。加载已有权重时，应保持相同的输入处理方式。

## 6. 训练配置与训练方法

### 6.1 当前默认参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `batch_size` | 8 | 每个训练批次的图片数量 |
| `num_workers` | 0 | 数据加载工作进程数量 |
| `learning_rate` | 0.0005 | 初始学习率 |
| `num_epochs` | 20 | 训练轮数 |
| `seed` | 2026 | 训练随机种子 |
| `momentum` | 0.9 | SGD 动量 |
| `weight_decay` | 0.0005 | 权重衰减 |
| `min_lr` | 0.000001 | 余弦退火的最低学习率 |
| `label_smoothing` | 0.1 | 训练标签平滑系数 |

命令行支持覆盖训练轮数、批次大小、初始学习率、工作进程数量和训练随机种子。其他参数在配置文件中设置。

### 6.2 训练流程

每轮训练执行：

1. 切换到训练模式。
2. 读取图片和标签并移动到运行设备。
3. 清空上一批次的梯度。
4. 前向传播并计算损失。
5. 反向传播并更新权重。
6. 在验证集上评估。
7. 更新余弦退火学习率。
8. 写入本轮指标；验证准确率提高时保存最佳模型。

训练损失使用带标签平滑的交叉熵，验证和测试使用普通交叉熵。两种损失的计算目标不同，不能只根据训练损失和验证损失的数值差判断过拟合。

每轮平均损失按样本数量加权计算；准确率为正确预测数量除以总样本数量。

验证和测试使用 `model.eval()` 与 `torch.no_grad()`。

## 7. 使用方法

以下命令均在项目根目录下执行，即包含 `train.py` 和 `environment.yml` 的目录。运行前应激活 `flower` 环境，并确保数据集位于项目目录下。

示例中的 `runs/20261021_213701` 为已记录的实验目录；使用自己训练的模型时，请替换为实际生成的实验目录。测试和预测需要该目录中的 `best.pt`，权重文件默认不随源码仓库上传。

### 7.1 训练模型

使用当前默认配置：

```bash
python train.py
```

显式指定部分训练参数：

```bash
python train.py \
  --epochs 100 \
  --batch-size 16 \
  --lr 0.001 \
  --num-workers 2 \
  --seed 2026
```

未通过命令行指定的参数仍采用当前配置文件中的值。上述命令不等同于精确复现历史最佳实验。

### 7.2 测试指定模型

`test.py` 的 `--checkpoint` 参数接收实验目录，程序会在目录后自动拼接 `best.pt`：

```bash
python test.py \
  --checkpoint runs/20261021_213701
```

程序输出模型轮次、保存的验证准确率、测试集数量、测试损失和测试准确率。

### 7.3 预测单张图片

`predict.py` 的 `--checkpoint` 参数接收实验目录，程序会在目录后自动拼接 `best.pt`：

```bash
python predict.py \
  --checkpoint runs/20261021_213701 \
  --image flower_photos/daisy/391364011_5beaaa1ae2_m.jpg
```

程序输出预测类别编号、类别名称和 softmax 概率。

softmax 概率表示模型在当前五个类别之间分配的概率，不代表经过校准的正确率。模型也没有实现未知类别识别。

### 7.4 绘制训练曲线

```bash
python plot_history.py \
  --run-dir runs/20261021_213701
```

绘图使用 `Agg` 后端，适合没有图形界面的服务器。

图片保存到对应实验目录中的 `training_curves.png`。

## 8. 实验文件与模型保存

每次训练创建一个以时间命名的实验目录，例如：

```text
runs/20261021_213701/
├── config.json
├── history.csv
├── best.pt
└── training_curves.png
```

其中：

- `config.json`：启动训练时采用的配置。
- `history.csv`：每轮训练和验证的指标。
- `best.pt`：验证准确率最高的检查点。
- `training_curves.png`：运行绘图脚本后生成的曲线图片。

CSV 字段为：

```text
epoch,train_loss,train_acc,val_loss,val_acc
```

CSV 中准确率使用 `0～1` 的小数，终端和曲线使用百分比显示。

检查点包含模型权重、优化器状态、调度器状态、模型轮次、验证指标、类别映射和训练配置。

当前只保存验证准确率严格提高时的模型；准确率相同时，保留较早保存的模型。虽然检查点包含优化器和调度器状态，当前训练入口尚未实现恢复训练功能。

## 9. 已验证的实验结果

目前保留的最佳实验为 `20261021_213701`。

已核对该实验的配置、100 轮训练记录及检查点元数据，最佳结果一致：

| 指标 | 结果 |
|---|---:|
| 最佳轮次 | 第 71 轮 |
| 最佳验证准确率 | **86.26%** |
| 验证集正确预测数量 | 314 / 364 |
| 该轮训练准确率 | 98.09% |
| 该轮验证损失 | 0.5411 |
| 第 100 轮验证准确率 | 84.89% |

这说明训练到最后一轮并不一定得到最佳验证结果，因此预测和测试应加载保存的最佳检查点。

该实验记录的主要参数为：

| 参数 | 记录值 |
|---|---:|
| 批次大小 | 16 |
| 数据加载工作进程 | 2 |
| 初始学习率 | 0.001 |
| 训练轮数 | 100 |
| 训练随机种子 | 2026 |
| SGD 动量 | 0.9 |
| 权重衰减 | 0.0005 |
| 最低学习率 | 0.00001 |


在当前数据条件下，从零训练得到 86.26% 验证准确率已经形成了可用的实验结果。
